# Reflexão A

Para a base do quadro Mondrian, comecei por criar uma canvas com 800 de altura e 785 de largura, mantendo o tamanho porpocional ao quadro. 
Para as linhas, comecei pela vertical, que embora pareça centrada encontra-se ligeiramente para a esquerda, formando assim 800 / 2 - 30. Em seguida, fiz as duas linhas horizontais a meio, seguindo a mesma lógica, e depois as pequenas linhas verticais e a pequena linha horizontal que serve de base para o quadrado azul. Para cada linha, tive em conta a grossura das mesmas na pintura original.
Feitas as linhas e a sua matemática, criei então os retêngulos. Para a sua cor, tanto como a do fundo, utilizei um color picker para obter a quantia exata em RGB.
